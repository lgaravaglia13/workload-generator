# Workload Schedule DSL
The **workload schedule** is a sequence of phases described by a DSL:

```bash
P1: Q:r,5,50,50,r; I:100,1,g,s; Q:p,10 | P2-5: Q:p,10,50,z; U:100,50,z,s; Q:r,10,50,50,r
```

Each phase defines a set of operations to execute; these operations are divided into two macro groups:

- **Query**: Point, Range, kNN (`Q:p`, `Q:r`, `Q:k`)
- **Write**: Update, Insert, Delete (`U`, `I`, `D`)

## Syntax Elements
   Element | Syntax | Description |
 |---|---|---|
 | **Single phase** | `P#:` | Targets a single phase (e.g., `P1:`). |
 | **Phase range** | `P#-$:` | Targets a range of consecutive phases, inclusive (e.g., `P2-5:`). |
 | **Phase separator** | `\|` | Separates phase definitions. |
 | **Operation separator** | `;` | Separates sequential operations within a single phase. |

All phases in a range execute the same list of operations.

---

## Operation Reference

Operations parameters are positional.

```text
Q:p,  <count>[,<percentile>,<dist>]
Q:r,  <count>,<offset>[,<percentile>,<dist>]
Q:k,  <count>,<k>[,<percentile>,<dist>]
U/I/D:<batchsize>,<percentile>,<dist>,<sortedness>
```

Every operations output are generated by sampling keys under the specified distribution
over a rank interval around the specified percentile. For queries, the
`<percentile>,<dist>` pair is optional: omitting it samples uniformly over
the entire active range.

### Query Operations

| Query | Parameter | Type / Values | Description |
|---|---|---|---|
| `Q:p` | — | — | **Point query**: single-key lookup. |
| `Q:r` | `offset` | `Integer >= 1` | **Range query**: retrieves all keys in the interval `[start_key, start_key + offset]`. |
| `Q:k` | `k` | `Integer >= 1` | **kNN query**. `k` is the number of nearest neighbors to return. |
| **Common parameters** | `count` | `Integer > 0` | Number of queries to generate. |
| | `percentile` | `Integer in [0,100]` | Percentile used as the rank interval pivot. |
| | `dist` | `g` \| `z` \| `r` | Weighting around the percentile pivot: `g` Gaussian, `z` Zipf, `r` uniform. |


**Example:** `Q:r,100,50,25,r` executes 100 range queries with interval
length 50 and draw uniform start keys from the 25th percentile.

### Write Operations
- `U`: **Update**: keys update.
- `I`: **Insert**: adds a batch of new keys.
- `D`: **Delete**: removes a batch of existing keys.

Write operations shares the same parameters:

 | Parameter | Type / Values | Description |
 |---|---|---|
 | `batch_size` | `Integer > 0` |  |
 | `percentile` | `Integer in [0,100]` | `= 0` prepends and `= 100` appends strictly outside the current key range. |
 | `dist` | `g` \| `z` \| `r` | Weighting around the percentile pivot: `g` Gaussian, `z` Zipf, `r` uniform. |
 | `sortedness` | `s` \| `u` | batch keys are sorted/unsorted. |


**Example:** `U:100,50,z,s` updates 100 records at the 50th percentile, Zipfian
distribution, sorted.

## Full Example

```bash
P1: Q:r,5,50,50,r; I:100,1,g,s; Q:p,10 | P2-5: Q:p,10,50,z; U:100,50,z,s; Q:r,10,50,50,r | P6-10: Q:r,5,50,50,r; I:100,1,g,s; Q:k,5,10,10,z
```

- **`P1: Q:r,5,50,50,r; I:100,1,g,s; Q:p,10`**
  - 5 range queries of interval length 50, uniform start keys in the rank window at the median
  - Insert 100 records at the 1st percentile, Gaussian distribution, sorted
  - 10 point lookups, uniform over the whole active set (short form)
- **`P2-5: Q:p,10,50,z; U:100,50,z,s; Q:r,10,50,50,r`** *(phases 2–5)*
  - 10 point lookups, Zipf-weighted in the rank window at the median
  - Update 100 records at the 50th percentile, Zipfian distribution, sorted
  - 10 range queries of interval length 50, uniform start keys in the rank window at the median
- **`P6-10: Q:r,5,50,50,r; I:100,1,g,s; Q:k,5,10,10,z`** *(phases 6–10)*
  - 5 range queries of interval length 50, uniform start keys in the rank window at the median
  - Insert 100 records at the 1st percentile, Gaussian distribution, sorted
  - 5 kNN queries (k=10), query points Zipf-clustered at the 10th percentile
